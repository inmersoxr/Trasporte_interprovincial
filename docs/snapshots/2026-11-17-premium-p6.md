# P6 — regresión, instalación PWA y handoff
Premium y miniapp incorporan SW por scope/cache independientes, shell offline sin datos privados y APIs/auth siempre fuera de caché. Instalar gestión abre /premium/?operator=UUID si perfil publicado; manifest no otorga privilegios. Interfaz offline informa que no se confirma ninguna operación. Compartir cuenta entre PWAs del mismo origen es intencional; roles/tenant se validan en servidor.
Se conservan requestId del formulario para reintentar costos y mantenimiento cuando se pierde respuesta, sin duplicación; cambio de datos reinicia la clave. Configuración de perfil añade reintento estable y mantiene control de revisión. Integridad de asignaciones ahora también en triggers D1 para impedir carreras entre revocación y asignación. Schema0012 aditivo. Readiness Google publica solo nombres de variables faltantes, nunca valores.
Validaciones previstas: suite local/CI completa; navegadores P1/P2/P3/P4/P5/A1/P6 y regresión demo/Standard/mercado/operaciones/PWA. P6 simula respuesta perdida tras commit de costo y reintenta, comprueba1 registro, móvil360/390/1280, shell offline y cachés. Estado implementación local, cierre remoto pendiente. Google real y Apple no se dan por verificados.
Rollback por versiones anteriores Workers/assets, conservando migraciones; cerrar mantenimientos abiertos antes de retirar consola, revocar membresías/invitaciones si se retira gestión, despublicar miniapps y retirar sesiones nuevas si se retira identidad. No borrar ledger, datos Standard ni Pages. No se ejecutan exports/restores nuevos; evidencia previa no sustituye respaldo duradero pendiente. Sin cobros ni upgrades; consumo/factura no medidos.
